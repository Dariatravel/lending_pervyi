## Шаг 1. Проверка сайта (локально)

```bash
# Supabase-ссылки на фото — должно быть 0 совпадений
rg -n 'storage/v1/object/public/site-media/(cards|hotels|kvartira|kvartira-cards|branding|blog|reviews)' \
  --glob '*.html' --glob '*.css' --glob '*.js' --glob '*.json' \
  --glob '!media/**' --glob '!output/**' --glob '!node_modules/**' --glob '!tmp/**'

# Локальные пути к фото в рабочих файлах — должно быть 0
rg -n '(?<![\w.-])(?:\.\./)+media/(cards|hotels|kvartira|kvartira-cards|branding|blog|reviews)|(?<![\w.-])/media/(cards|hotels|kvartira|kvartira-cards|branding|blog|reviews)|(?<![\w./:-])media/(cards|hotels|kvartira|kvartira-cards|branding|blog|reviews)' \
  --pcre2 --glob '*.html' --glob '*.css' --glob '*.js' --glob '*.json' \
  --glob '!media/**' --glob '!output/**' --glob '!node_modules/**' --glob '!tmp/**'

# Видео на Supabase — должны остаться (это норма)
rg -n 'site-media/videos' --glob '*.html' --glob '*.js' | head
```

Автозамена (если снова появятся Supabase-фото в HTML):

```bash
python3 tools/fix_supabase_photo_urls_in_site.py
```

  media/cards media/hotels media/kvartira media/kvartira-cards \
