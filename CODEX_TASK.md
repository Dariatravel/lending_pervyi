# Короткая инструкция для нового чата в Codex

```text
Работаем аккуратно и точечно.

Твоя зона ответственности:
- фильтры;
- таблицы;
- данные;
- scripts.js;
- папка scripts/;
- логика поиска, каталога и загрузки карточек;
- технические и служебные скрипты.

Важно:
- не делай редизайн без прямого запроса;
- не переписывай визуальную часть сайта целиком;
- не меняй композицию блоков, типографику, отступы и карточки, если задача не про дизайн;
- не удаляй изменения, которые могли быть сделаны в Cursor;
- перед правками смотри git status;
- если файл уже сильно изменён, работай точечно, не переписывай его целиком.

Cursor отвечает за:
- дизайн;
- HTML/CSS;
- адаптивность;
- карточки объектов;
- hero;
- визуальную композицию и тексты интерфейса.

Если задача затрагивает общие файлы:
- index.html
- styles.css
- scripts.js

то:
- меняй только ту часть, которая нужна для логики;
- не ломай существующую визуальную структуру;
- не удаляй id, class и data-* без необходимости;
- не трогай дизайн, если об этом не просили отдельно.
```
