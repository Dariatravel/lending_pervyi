# Трекер кешбека

Приложение для учета категорий кешбека по банкам и месяцам. Работает локально и подходит для деплоя на Railway.

## Как запустить

```bash
cd "/Users/darya_botova/Documents/New project/cashback_tracker"
python3 server.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:8765
```

## Где лежат данные

Данные сохраняются в файл:

```text
/Users/darya_botova/Documents/New project/cashback_tracker/cashback-data.json
```

Для Railway можно подключить volume и хранить данные в переменной окружения
`RAILWAY_VOLUME_MOUNT_PATH`. Тогда `cashback-data.json` будет сохраняться в persistent storage.

## Деплой на Railway

Приложение готово для деплоя через `Dockerfile`.

Что важно:

1. Railway должен пробросить переменную `PORT`.
2. Для постоянного хранения данных лучше подключить volume.
3. Если volume подключен, приложение автоматически будет использовать
   `${RAILWAY_VOLUME_MOUNT_PATH}/cashback-data.json`.

## Как использовать

1. Добавьте список банков один раз.
2. Выберите месяц.
3. Внесите категории вручную или вставьте строки формата `Банк | Категория | % | Лимит | Комментарий`.
4. Если удобно, используйте кнопку копирования данных из прошлого месяца и затем поправьте изменения.
5. Сводка внизу покажет лучший кешбек по каждой категории.

## Для совместной работы со мной

Если вы присылаете мне новые категории за месяц, я могу обновлять `cashback-data.json` напрямую, и приложение сразу будет показывать актуальную историю.
