Высокий приоритет

1. Исправить конфликт Telegram-сессии `database is locked`.
- Сейчас несколько Telethon-скриптов используют один `tg_session.session`.
- Нужно добавить общий lock-механизм или отдельные session-файлы для бота/ручных проверок.
- Затронутые скрипты: `watch_telegram_updates.py`, `audit_telegram_site_prices.py`, `audit_telegram_site_parity.py`, `sync_catalog_from_telegram.py`.

2. Убрать зависания Telegram-проверок.
- `watch_telegram_updates.py` зависал дольше 5 минут.
- Добавить внутренние таймауты, retry и понятный выход с ошибкой.
- Бот уже имеет общий timeout, но сами скрипты должны завершаться предсказуемо.

3. Улучшить Telegram-бот при сетевых ошибках.
- В логах есть `httpx.ConnectError: nodename nor servname provided`.
- Нужно сделать русское сообщение: “Нет соединения с Telegram / проблема DNS, бот повторит позже”.
- Не считать это поломкой сайта.

4. Проверить и поправить `audit_telegram_site_prices.py`.
- Сейчас проверка цен не прошла из-за `database is locked`.
- После исправления session-lock повторно запустить аудит и посмотреть реальные расхождения.

Средний приоритет

5. Навести порядок с runtime-файлами `output/`.
- В рабочем дереве много старых untracked логов.
- Решить: добавить нужные runtime-папки в `.gitignore` или сделать отдельную команду очистки старых логов.
- Не удалять отчёты, которые нужны для диагностики.

6. Добавить health-check команду для сайта и бота.
- Один скрипт, например `tools/health_check.py`, который проверяет:
  - `validate_catalog_snapshot.py`
  - `verify_object_media.py`
  - `sync_objects_map_points.py`
  - Telegram watch без применения изменений
  - статус launchd-бота
- В конце выдаёт понятный русский отчёт.

7. Улучшить сообщения бота по итогам проверки.
- Разделить:
  - “Новые изменения найдены”
  - “Сайт актуален”
  - “Техническая проблема проверки”
- Не показывать пользователю пугающие технические коды без объяснения.

8. Проверить Python-окружение.
- Сейчас используется Python `3.9.6`, библиотеки Google уже предупреждают, что версия устарела.
- Подготовить переход на Python `3.10+` или `3.11`, особенно для автозапуска.
